HERO PHOTOGRAPH
===============

Save the laboratory photograph in this folder as exactly:

    hero-lab.jpg

The home page picks it up automatically on the next build. Until the file
exists, the hero falls back to the certificate-of-analysis panel, so the page
is never broken by a missing image.

Recommended: roughly 1700 x 900 px or larger, landscape, JPEG, under ~400 KB.
Keep the left third of the frame visually calm — on wide screens the headline
sits alongside it and the image is feathered into the page from that edge.

If you use a different filename or format, update HERO_IMAGE in
src/components/HeroMedia.tsx to match.

Only publish photographs you own or are licensed to use.
